# Sistema de Administración de Citas para un Consultorio Clínico

Proyecto en Java listo para abrir y ejecutar en NetBeans.

## Instalación y configuración

1. Instalar JDK 11.
2. Instalar Apache NetBeans.
3. Abrir NetBeans.
4. Seleccionar `File > Open Project`.
5. Elegir la carpeta `SistemaCitasClinicas_NetBeans`.
6. Ejecutar el proyecto con `Run Project`.

## Uso del programa

Usuario inicial de administrador:

- Identificador: `admin`
- Contraseña: `1234`

El sistema permite:

- Dar de alta doctores.
- Dar de alta pacientes.
- Crear citas con fecha y hora.
- Relacionar una cita con un doctor y un paciente.
- Listar doctores, pacientes y citas.
- Guardar la información en archivos CSV dentro de la carpeta `db`.
